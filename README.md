# RhinoFlow PNIF

Калькулятор референсных значений пикового назального инспираторного потока (ПНИП) у детей и подростков (6,5–18,5 лет).

**Открыть калькулятор:** https://pnifcalc.github.io/pnif-calculator/

Инструмент носит справочный характер и не заменяет клиническую оценку.
